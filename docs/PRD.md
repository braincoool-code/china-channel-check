# 사이트 설계도(PRD) — (미정: 사이트 이름)

작성일: 2026-10-11 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
중화권 10년 경험에 AI를 더해, 중국과 일하는 기업의 판매 채널을 점검하고 중국·AI 강의를 하는 곳.

## 2. 손님
- 누가: 중국과 일하는 기업의 대표, 그리고 교육 담당자
- 어디서 알고 오나: 검색·블로그, 링크드인·인스타 등 SNS

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 판매 채널 점검으로 우리 회사의 어떤 문제를 해결해 주나
2. 진행 방식·기간 (몇 회, 몇 시간, 온라인/방문) — (미정: 사용자에게 받아서 채움)
3. 비용 — 최초 점검은 무료, 본 점검·강의는 견적

## 4. 믿게 할 증거 (실제로 있는 것만)
- 강의 이력 목록 — (내용 받아서 채움: 기관·기업 이름, 주제, 날짜)
- 중화권 실무 경력 10년 — (내용 받아서 채움: 회사·역할·기간)
- 강의·현장 사진 — (사진 파일 받아서 채움)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 판매 채널 점검 신청
- 누르면: 문의 폼 (강의 문의도 같은 폼에서 받음)

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + [판매 채널 점검 신청] 버튼 + "최초 점검은 무료"
2. 판매 채널 점검 — 어떤 문제를 해결하나 / 진행 방식·기간 / 비용(최초 무료, 이후 견적)
3. 중국·AI 강의 — 강의 주제와 강의 이력 목록 (교육 담당자용)
4. 경력 — 중화권 실무 10년, 강의·현장 사진
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 회사명, 지금 쓰는 중국 판매 채널
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 최초 점검은 무료. 본 점검·강의 금액은 (미정 — 견적으로 안내)
- 시간: (미정)
- 위치: (미정 — 온라인/방문 여부 포함)
- 연락 방법: 사이트 문의 폼. 그 밖의 연락처는 (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인 (다음에)
- 결제
- 블로그 (검색 유입용으로 다음에)
- 알림 메일 (문의는 /admin에서 확인)
- 중국어·영어 버전

## 10. 첫 화면 한 문장 후보
1. 중국 판매 채널, 10년 현장 경험과 AI로 점검해 드립니다
2. 중국에서 왜 안 팔리는지, 채널부터 같이 봅니다
3. 중화권 10년의 감각에 AI를 더한 판매 채널 점검

## 11. 다음에 할 것
- 강의 이력·경력·사진 실제 내용 채우기
- 진행 방식·기간, 연락처, 사이트 이름 정하기
- 실제 후기가 생기면 후기 자리에 넣기
- 검색 유입을 위한 블로그·SEO
- 링크드인·인스타 프로필에 사이트 링크 걸기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
